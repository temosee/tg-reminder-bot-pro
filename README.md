# tg-reminder-bot

Telegram-бот для напоминаний с разбором естественного языка на русском.

## Что умеет

- Разовые напоминания: `напомни в 15:00 позвонить маме`
- Повторяющиеся: `напоминай пить воду каждые 2 часа`
- По будням и выходным: `напоминай по будням в 9:00 делать зарядку`
- Со сроком окончания: `напоминай каждый день в 9:00 пить таблетки до 1 сентября`
- День недели: `напомни в пятницу сдать отчёт`
- Слова словами: `напомни через пять минут поесть`
- Перенос уже созданного напоминания кнопкой из списка
- Перенос сработавшего: +15 мин, +30 мин, +1 час, +3 часа, +6 часов, завтра
- Голосовые сообщения (распознавание через Whisper)
- Заметки без времени: `запомни: пароль от вайфая 12345`
- Часовой пояс по городу: `Москва`, `мск`, `спб`, `екб`, `нск`, `вдк`

Тексты напоминаний и заметок хранятся в базе зашифрованными (Fernet), ключ живёт
в переменной окружения. Дамп базы без ключа бесполезен.

При смене города напоминания, заданные временем на часах («в 9:00», «утром»),
остаются на том же времени в новом поясе. Заданные длительностью («через 4 часа»)
не двигаются — момент срабатывания сохраняется.

## Команды

```
/start     — начало работы, запрос города
/help      — то же, что /start
/timezone  — сменить город
/stats     — своя статистика
/admin     — сводка и список пользователей (только для владельца)
```

## Стек

- Python 3.12
- python-telegram-bot 21
- APScheduler
- PostgreSQL (psycopg2)
- dateparser, geopy, timezonefinder
- cryptography — шифрование текстов в базе
- groq — распознавание голосовых

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env  # заполнить значения
python bot.py
```

## Переменные окружения

```
BOT_TOKEN              — токен от @BotFather
DATABASE_URL           — postgres://...
ADMIN_ID               — Telegram user_id владельца, можно несколько через запятую
ENCRYPTION_KEY         — ключ Fernet для шифрования текстов (необязательно)
GROQ_API_KEY           — для распознавания голосовых (необязательно)
DEFAULT_TIMEZONE       — Europe/Moscow по умолчанию
DB_POOL_SIZE           — соединений к базе, по умолчанию 10
MAX_REMINDERS_PER_DAY  — 20
MAX_ACTIVE_REMINDERS   — 50
MAX_NOTES              — 100
MAX_MSG_LENGTH         — 200
FLOOD_LIMIT            — 5 сообщений
FLOOD_WINDOW           — за 10 секунд
MAX_NEW_USERS_PER_HOUR — 30
```

Ключ шифрования генерируется так:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Если ключ не задан, бот работает, но пишет тексты в базу открытыми и предупреждает
об этом в логах. Потеря ключа означает, что старые записи не расшифровать.

## Структура

```
bot.py         — handlers, запуск
parser.py      — разбор русского текста
scheduler.py   — APScheduler jobs
db.py          — PostgreSQL, пул соединений
crypto.py      — шифрование текстов
config.py      — переменные окружения
middleware.py  — антифлуд, лимиты
admin.py       — сводка и список пользователей
city_tz.py     — определение часового пояса по городу
translations.py — тексты сообщений
test_parser.py — тесты парсера
test_db.py     — тесты пула соединений и лимитов
test_bot.py    — тесты сборки сообщений и планировщика
```

Railway: настроен `railway.json` и `Procfile`. База — PostgreSQL, схема создаётся
